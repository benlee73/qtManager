# QT Manager 0.4.0

- ‘또래 해당 없음’이 정보 수정 되돌리기에서 해제되는 오류를 수정했습니다.
- 신청자 관리의 배부 행에 마우스를 올리면 작은 ×가 나타납니다. 확인 후 선택한 배부만 취소하며 원본과 변경 이력은 남습니다. 군지체와 일반 신청자 모두 지원합니다.
- 1달 구독은 구독 이력과 배부 이력에 각각 표시합니다. 배부만 취소하면 구매·입금 상태는 유지하고 현장 배부에서 다시 전달할 수 있습니다.
- 1달 구독의 시작 호·권수를 정정해도 실제 배부 호·권수·시각은 유지합니다. 불일치는 확인 후 저장합니다.
- 입금 확인이 독립된 배부 원장을 덮어쓰지 않도록 저장 범위를 제한했습니다.

SQLite schema 8 / XLSX 형식 5. 이전 형식 1~4 백업을 가져올 수 있습니다. 새 v5 백업을 받을 기기에는 0.4.0 이상을 설치하세요. DB 업그레이드 전 안전 사본을 자동 생성합니다.

이미 잘못 해제된 또래 예외는 자동으로 판별할 수 없으므로 해당 신청자의 ‘해당 없음’을 다시 체크하세요.

macOS·Windows Actions에서 E2E 각 33개와 설치 패키지 검사를 통과했습니다. Windows는 무인 설치 후 GUI 실행도 확인했습니다. 실제 Windows 10/11 및 Intel Mac 장치에서의 설치 확인은 별도로 진행합니다.
