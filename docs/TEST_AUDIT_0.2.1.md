2026-10-19 `just check` 통과: Python 2개, 프론트엔드 164개, Rust 전체 검사, 포맷·lint·E2E 엄격 타입 검사. 화면 E2E 실행 결과는 릴리스 체크리스트와 함께 기록한다. 미실행 환경은 통과로 표시하지 않는다. 운영 데이터나 실제 인원 fixture를 사용하지 않는다.

에이전트 환경의 `just e2e`는 앱 컴파일 후 onPrepare에서 embedded WebDriver 서버 준비가 60000ms를 초과해 종료됐다. 실제 화면 테스트 통과 수는 0이며 테스트 실패와 실행 환경 시작 실패를 구분한다. 일반 터미널에서 `pnpm_config_verify_deps_before_run=false just e2e > target/qt-021-e2e-user.log 2>&1`로 실행한 뒤 로그를 확인한다.

## 2026-10-25 릴리스 전 실제 화면 검사

일반 터미널 실행에서 28개 통과·1개 실패를 확인했다. 실패는 새 헤더에서 공통 높이 36px을 사용하는 제목을 이전 텍스트 상자 기준인 32px 이하로 제한한 검사였다. 제목·간략·자세히·검색·닫기 다섯 요소의 실제 높이가 모두 36px이고 수직 중심이 1px 이내로 일치하는지 검사하도록 대체했다. 기존 줄바꿈 방지·본문 공간·검색·목차 검사는 유지한다. 수정 후 실제 화면 재실행 및 양 OS Actions 결과는 대기 중이다.
