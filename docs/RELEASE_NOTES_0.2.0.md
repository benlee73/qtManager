# QT Manager 0.2.0

- 현장 배부를 전체 필터로 시작하고 만료·예정·구독 없는 신청자도 조회합니다. 개별 필터의 실제 클릭과 키보드 조작 검사를 보강했습니다.
- 메모를 보관·삭제해도 남던 표시와 삭제한 메모가 백업에서 되살아날 수 있던 경로를 수정합니다.
- 또래 ‘해당 없음’과 한글 조합 중 검색을 지원합니다. `/`로 검색 내용을 전체 선택하고 검색창의 Esc로 지웁니다.
- 1년 구독 시작 호를 선택합니다. 현재 호는 ‘신청 + 배부’가 기본이며 다음 호 시작은 신청만 저장합니다. 1달 구독은 현재 호 즉시 전달을 유지합니다.
- 이력의 연필 버튼에서 연간·1달 구독을 정정하고 원본·실제 배부와 정정 이력을 보존합니다.
- Windows 메뉴 줄바꿈과 콘솔 실행 문제를 수정하고 도움말에 간략·자세히 보기를 제공합니다.

이전 백업을 읽을 수 있습니다. 새 백업은 XLSX v4이므로 받는 기기에 0.2.0을 먼저 설치하세요. 앱 업데이트 시 SQLite 안전 사본을 만든 뒤 v7로 이전합니다.

현재 검증과 설치 파일 생성 상태는 RELEASE_CHECKLIST.md를 확인하세요.
