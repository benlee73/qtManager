# QT Manager 0.2.1

- 또래 ‘해당 없음’을 선택하면 기존 값을 지우고 입력을 비활성화합니다. 목록 배지는 --로 표시합니다.
- 현장 배부의 만료 행에서도 Enter로 구독 추가를 엽니다.
- 구독 창에서 신청자를 선택하면 연결 상자만 표시하고 선택 해제로 다시 검색합니다. 시작 연도와 호의 높이를 맞췄습니다.
- 구독 이력의 상태와 연필 버튼을 나란히 표시합니다. 정정에서는 시작 연도·호·권수만 입력하고 기존 날짜와 메모는 유지합니다.
- 도움말 제목·보기 방식·검색을 정렬하고 간략 안내를 배부 시나리오·백업과 이동·단축키의 카드로 줄였습니다.

데이터 형식은 SQLite v7·XLSX v4로 유지합니다. 이전 백업을 계속 사용할 수 있습니다.
