# 1달 구독 배부 분리 및 전체 배부 행 취소 구현 계획

**Goal:** 구매·입금과 배부를 독립시키고 모든 신청자의 선택 배부 기록을 안전하게 취소·재배부한다.
**Architecture:** 연간 Distribution 원장은 유지한다. 1달 구독의 OneTimePurchase에는 독립 ID·호·권수·처리 시각·취소 관계를 가진 배부 원장을 추가한다. 저장 어댑터는 JSON 열로 왕복하며 업무 규칙은 domain/application에서 판단한다. 기존 JSON 열이 없는 구매는 최초 전달 한 건으로 해석하므로 구버전 백업을 반복해 읽어도 중복 생성하지 않는다. 정정 대체 구매는 실제 배부 원장을 그대로 승계한다.
**Tech Stack:** Rust / SQLite schema 8 / XLSX v5 / Tauri / React, 앱 0.4.0. 의존성 추가 없음.
**Spec:** PROJECT_SPEC.md FR-SALE, FR-SUB, FR-DIST, FR-GROUP, FR-UNDO.

## 확인된 사용자 결정

- 전체 신청자의 유효한 배부 행에서 hover/focus 투명 ×, 확인 후 해당 ID 취소.
- 1달 신청 시 구독 이력과 배부 이력 각각 한 건, 구매·입금과 배부 취소 독립.
- 배부 취소 후 미배부로 돌아가 같은 신청으로 재배부 가능.
- 1달 정정은 배부 보존, 호·권수 불일치 확인 후 저장.
- 또래가 없는 일반인은 누락 표시 유지, 명시적인 해당 없음은 예외.

## 검토할 실패 조건

- 동일 시각·수량인 다른 기록 취소, 중복 제출: ID와 트랜잭션 CAS 검증.
- 연간·1달 동시 자격: 목표·배부 합산, 서로의 기록에 영향 없음.
- 1달 정정으로 과거 전달 호가 달라짐: 원래 호·수량·시각 보존 및 확인 필수.
- 구버전 XLSX·SQLite: 기본 전달 한 건만 해석, 그룹과 금융 취소는 제외.
- 배부 취소·재배부·Undo/Redo·입금 변경·백업 왕복: 원장/프로필/입금 상태 보존.
