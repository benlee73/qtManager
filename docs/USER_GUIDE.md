# QT Manager 담당자 사용 안내

> 앱 버전 0.1.0 · 지원: macOS 12 이상, Windows 10/11 64비트

## 1. 설치와 최초 실행

이 앱은 인터넷과 로그인이 필요 없는 내부 배포용 프로그램이다. 신뢰할 수 있는
담당자에게 받은 설치 파일인지 먼저 확인한다.

### macOS

1. DMG를 열고 `QT Manager`를 Applications 폴더로 옮긴다.
2. 서명되지 않은 앱 경고가 나오면 앱을 한 번 실행한 뒤 `시스템 설정 → 개인정보
보호 및 보안 → 그래도 열기`를 선택한다.
3. Apple Silicon과 Intel을 모두 포함한 Universal 설치 파일을 사용한다.

### Windows

1. `QT Manager_*_x64-setup.exe`를 실행한다.
2. SmartScreen 경고가 나오면 파일을 받은 경로를 다시 확인한 뒤 `추가 정보 →
실행`을 선택한다.
3. 설치가 끝나면 시작 메뉴에서 QT Manager를 실행한다.

최초 실행 시 현재 담당자 이름을 입력한다. 계정은 만들어지지 않으며 이후 업무
변경 이력에 당시 담당자 이름만 남는다. 첫 실행은 다크 테마이며 이후에는 마지막
테마 선택을 이 컴퓨터에서 유지한다. 창 크기는 조절할 수 있으며 목록 스크롤
막대는 라이트·다크 테마에 맞춰 표시된다.

## 2. 현장 배부

1. 상단에서 배부할 QT 호를 확인한다.
2. `필터`에서 남은 배부, 전체 또는 상태별 목록을 고른다. 검색 중에도 선택한
   필터가 적용된다.
3. 이름 일부, 또래, `94 홍`, 전화번호 숫자로 신청자를 찾는다.
   또래·신청자·구독·배부 머리글을 누르면 오름차순/내림차순으로 정렬된다.
4. 책을 전달한 뒤 행의 `N권 배부`를 누른다. 2권 신청자는 기본 버튼 한 번으로
   2권 모두 처리된다.
5. 일부만 전달했다면 `일부만 배부`에서 실제 수량을 선택한다.
6. 완료 배부를 취소하려면 해당 행의 `배부 취소`를 누르고 대상자를 확인한다.
   취소 이력은 남으며 다시 배부할 수 있다.

구독 자격은 오늘 날짜가 아니라 선택한 QT 호를 기준으로 계산한다. `이번 호가
마지막`인 신청자에게는 다음 호부터 새 신청이 필요하다고 안내한다.

## 3. 신규 신청과 예외 기록

- 모든 정보를 알면 `신청자 관리 → QT 신청자 추가`에서 정식 등록한다.
- 배부 목록의 신청자를 더블클릭하거나 점 세 개·우클릭 메뉴에서 정보를 수정한다.
- 한 사람의 여러 권이 서로 다른 기간이면 권별 구독을 따로 추가한다. 배부
  목록은 현재 호에 해당하는 권수를 한 행에 합산하고 상세에는 각 기간을 보존한다.
- 현장에서 바로 신청하고 책을 받으면 `현장 간이 등록` 후 해당 호를 배부한다.
  연락처는 나중에 신청자 상세에서 보완할 수 있다.
- Google 응답은 `신청자 관리 → Google 응답 붙여넣기`에 한 행 또는 여러 행을
  붙여넣고 미리보기·중복 후보를 확인한 뒤 반영한다. 입금 여부는 저장하지 않는다.
- 한 호만 현장에서 구매하면 `더보기 → 현장 개별 구매`를 사용한다. 구독 배부
  상태에는 영향을 주지 않는다.
- 한 번 확인하고 끝낼 사항은 `확인할 일`, 전체 담당자가 계속 볼 운영 정보는
  `고정 메모`, 개인별 지속 정보는 `신청자 메모`에 적는다.
- 확인할 일의 빈 체크박스는 확인 필요, 체크된 상태는 확인 완료를 뜻한다. 보관한
  확인할 일과 고정 메모는 배부 화면의 `보관함`에서 확인하고 복원한다.
- 더 이상 필요 없는 확인할 일과 고정 메모는 삭제 확인 후 영구 삭제할 수 있다.
- 확인할 일·고정 메모의 추가, 완료, 보관과 복원 직후에는 상단 되돌리기/다시
  실행 버튼 또는 `⌘/Ctrl+Z`, `⌘/Ctrl+Shift+Z`를 사용할 수 있다.

## 4. 데이터 인수인계

1. 기존 담당자가 `신청자 관리 → 데이터 인수인계 → 전체 상태 내보내기`를 한다.
2. 생성된 XLSX의 요약 건수를 확인한다.
3. 파일에는 전체 이름과 전화번호가 있고 암호화되지 않으므로 안전하게 전달한다.
4. 새 담당자는 같은 버전 또는 호환 최신 앱에서 파일을 선택한다.
5. 새 PC의 상태만 사용할 때는 `교체`, 양쪽 작업을 합칠 때는 `병합`을 선택한다.
6. 동일인 후보와 변경 요약을 확인한 뒤 가져온다.
7. 결과가 잘못되면 앱을 재실행한 뒤에도 `가져오기 되돌리기`를 사용할 수 있다.
8. 인수인계가 끝나면 메일·메신저·다운로드 폴더의 불필요한 XLSX 사본을 삭제한다.

## 5. 문제 해결과 로그

앱의 `도움말 → 앱 정보`에서 정확한 앱 버전, 데이터 위치와 로그 위치를 확인할
수 있다. `로그 폴더 열기`로 `qt-manager.log`와 회전 파일을 찾는다. 로그에는
이름·전화번호·메모를 기록하지 않지만, 전달 전 내용과 수신자를 다시 확인한다.

앱이 실행되지 않으면 운영체제, 앱 버전, 발생 시각, 보이는 오류 문구와 로그를
개발 담당자에게 전달한다. 운영 XLSX나 SQLite 파일은 개인정보가 포함되므로 문제
재현에 꼭 필요한지 확인하지 않고 전달하지 않는다.

## 6. 백업, 퇴임과 앱 삭제

- 전체 상태 가져오기 전 자동 복원 지점은 최신 10개가 로컬에 보관된다.
- 중요한 변경 전에는 전체 상태 XLSX를 별도 안전한 위치에 내보낸다.
- 앱 삭제만으로 로컬 데이터가 함께 삭제된다고 가정하지 않는다.
- 퇴임 담당자는 인수인계 완료와 새 담당자의 표본 확인 후, `도움말 → 앱 정보`에
  표시된 데이터 폴더와 개인적으로 보관한 XLSX 사본을 조직 정책에 따라 삭제한다.
- 데이터 폴더를 지우면 앱 상태와 자동 복원 지점을 되찾기 어려우므로 대상 경로를
  확인하고 앱을 완전히 종료한 뒤 처리한다.
