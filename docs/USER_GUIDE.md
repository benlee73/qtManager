# QT Manager 담당자 사용 안내

> 앱 버전 0.1.0 · 지원: macOS 12 이상, Windows 10/11 64비트

## 1. 설치와 최초 실행

이 앱은 인터넷과 로그인이 필요 없는 내부 배포용 프로그램이다. 신뢰할 수 있는
담당자에게 받은 설치 파일인지 먼저 확인한다.

### macOS

1. DMG를 열고 `QT Manager`를 Applications 폴더로 옮긴다.
2. 서명되지 않은 앱 경고가 나오면 앱을 한 번 실행한 뒤 `시스템 설정 → 개인정보
보호 및 보안 → 그래도 열기`를 선택한다.
3. Apple Silicon과 Intel을 모두 포함한 Universal 설치 파일을 사용한다.

### Windows

1. `QT Manager_*_x64-setup.exe`를 실행한다.
2. SmartScreen 경고가 나오면 파일을 받은 경로를 다시 확인한 뒤 `추가 정보 →
실행`을 선택한다.
3. 설치가 끝나면 시작 메뉴에서 QT Manager를 실행한다.

최초 실행 시 현재 담당자 이름을 입력한다. 계정은 만들어지지 않으며 이후 업무
변경 이력에 당시 담당자 이름만 남는다. 첫 실행은 다크 테마이며 이후에는 마지막
테마 선택을 이 컴퓨터에서 유지한다. 창 크기는 조절할 수 있으며 목록 스크롤
막대는 라이트·다크 테마에 맞춰 표시된다.

폭 76px의 왼쪽 메뉴에서 현장 배부, 신청자 관리, 도움말과 테마를 전환한다.
선택한 메뉴는 배경과 왼쪽 강조선으로 표시된다. 아래 담당자 이름을 누르면 현재
담당자를 바꿀 수 있다.

도움말은 왼쪽 목차에서 필요한 항목을 고른다. 현장 배부나 신청자 관리에서 열면
현재 화면과 관련된 항목으로 바로 이동하며, 본문을 스크롤하면 목차의 선택도 함께
바뀐다. 본문은 업무 카드와 짧은 목록으로 정리되어 있으며, 섹션 제목은 스크롤 중
상단에 남는다. `메모`에서 신청자 연결 메모와 미연결 메모의 사용법을 확인할 수 있다.
도움말은 `Escape`로 닫을 수 있고, 앱 정보의 데이터·로그
경로는 줄바꿈된 전체 값이나 마우스 오버 툴팁으로 확인한다.

## 2. 현장 배부

1. 상단에서 배부할 QT 호를 확인한다.
2. `필터`에서 미배부, 일부 배부, 배부 완료, 구독 만료를 여러 개 고른다.
   `남은 배부`와 `전체` 빠른 선택을 사용할 수 있고 검색 중에도 선택한 필터가
   적용된다. 닫힌 버튼은 선택 종류와 개수를 요약하며 마우스를 올리면 선택한
   상태 전체를 확인할 수 있다.
3. 이름 일부, 또래, `94 홍` 조합으로 신청자를 찾는다. 전화번호는 신청자 관리에서
   확인·검색한다.
   또래·신청자·구독·배부 머리글을 누르면 오름차순/내림차순으로 정렬된다.
   검색창에서 `ArrowDown`을 누르면 첫 신청자로 이동하고, 목록에서 위·아래
   방향키로 한 명씩 이동할 수 있다. 선택 행에서 `Enter`를 누르면 배부 확인창이
   열리고, 다시 `Enter`를 누르면 배부한다. 첫 행에서 `ArrowUp`은 검색창으로
   돌아가며, `ArrowRight`·`ArrowLeft`로 행과 오른쪽 메모 입력 사이를 오갈 수 있다.
4. 책을 전달한 뒤 행의 `N권 배부`를 누른다. 2권 신청자는 기본 버튼 한 번으로
   2권 모두 처리된다.
5. 일부만 전달했다면 `일부만 배부`에서 실제 수량을 선택한다.
6. 완료 배부를 취소하려면 해당 행의 `배부 취소`를 누르고 대상자를 확인한다.
   취소 이력은 남으며 다시 배부할 수 있다.

구독 자격은 오늘 날짜가 아니라 선택한 QT 호를 기준으로 계산한다. `이번 호가
마지막`인 신청자에게는 다음 호부터 새 신청이 필요하다고 안내한다. 신청자 관리의
구독 상태는 오늘이 포함된 호를 기준으로 현재·예정·지난·보관으로 나누어 보이지만,
이는 관리용 분류일 뿐 현장 배부 자격을 바꾸지 않는다.

현장 배부 표에는 전화번호 열을 상시 표시하지 않는다. 이름에 마우스를 올리거나
신청자 행을 더블클릭해 정보 수정 화면을 열면 전체 번호를 확인할 수 있다. 신청자
관리 화면에서는 전화번호 숫자로도 검색할 수 있다.
연락처를 등록·수정할 때는 숫자만 입력해도 `010-xxxx-xxxx` 하이픈이 자동으로
들어가며, 저장되는 번호도 이 형식으로 통일된다. 비어 있는 연락처는 허용되지만
010으로 시작하지 않는 번호는 저장할 수 없다.

## 3. 신규 신청과 예외 기록

- 모든 정보를 알면 `신청자 관리 → 신청자 등록`에서 등록한다.
- 배부 목록의 신청자를 더블클릭하거나 점 세 개·우클릭 메뉴에서 정보를 수정한다.
- 한 사람의 여러 권이 서로 다른 기간이면 권별 구독을 따로 추가한다. 배부
  목록은 현재 호에 해당하는 권수를 한 행에 합산하고 상세에는 각 기간을 보존한다.
- 현장에서 바로 신청하고 책을 받으면 이름을 입력해 `현장 간이 등록` 후 해당 호를
  배부한다. 또래와 연락처는 나중에 신청자 상세에서 보완할 수 있다.
- 스프레드시트·엑셀 응답은 `신청자 관리 → 스프레드시트 붙여넣기`에 한 행 또는 여러 행을
  붙여넣고 미리보기·중복 후보를 확인한 뒤 반영한다. 입금 여부는 저장하지 않는다.
- 한 호만 현장에서 구매하면 `더보기 → 현장 개별 구매`를 사용한다. 이름·또래를
  입력해 기존 신청자를 검색한 뒤 결과를 직접 선택하면 구매 이력이 그 사람의
  상세에 연결된다. 찾는 사람이 없으면 `신규 인원으로 추가`를 선택해 구독 없는
  구매 전용 신청자를 만들 수 있으며, 이름을 비워 익명으로 기록할 수도 있다.
  어느 경우에도 구독 배부 상태에는 영향을 주지 않는다.
- 메모는 현장 배부 오른쪽에서 바로 만들거나, 신청자 행의 점 세 개·우클릭 메뉴와
  신청자 상세에서 특정 신청자에 연결해 만든다. 미연결 메모에는 별도 유형 표시가
  붙지 않는다.
- 현장 배부에서 이름·또래를 검색하면 일치하는 신청자의 연결 메모가 우측 목록
  상단으로 올라옵니다. 다른 메모는 아래에 유지되고, 검색어를 지우면 최근 수정
  순으로 돌아갑니다.
- 메모 입력은 저장 전에도 이 컴퓨터의 로컬 초안으로 남는다. 저장에 성공하면
  초안이 지워진다.
- 신청자 관리 목록은 빠르게 찾을 수 있도록 또래와 이름만 기본 표시하며
  전화번호를 표시하지 않는다. 정보 보완 필요·보관 상태는 작은 표시로 구분하고,
  상단의 `정보 보완 필요 N명`은 현장 간이 등록 상태가 아직 보완되지 않은
  신청자 수를 뜻하며, 일반 등록자의 또래 누락이나 입금 상태를 의미하지 않는다.
  구독 건수와 마지막 대상 호는 행 안내 또는 상세에서 확인한다. 전체 전화번호는
  신청자를 선택한 상세 또는 정보 수정 화면에서 확인한다. 연결 메모는 상세의
  연락처 아래에 항상 보이며 입력칸에서 바로 추가한다. 메모가 없을 때는 입력칸
  옆 안내 툴팁만 보이며 노란 경고가 아니다.
- 신청자 관리 상단에는 `신청자 관리` 제목 하나만 표시된다. 긴 신청자 목록은 왼쪽
  목록 안에서, 긴 구독·배부 이력은 오른쪽 상세 안에서 각각 스크롤한다. 인물 상세에서는
  또래 배지 오른쪽에 이름이 표시되고 연락처와 상태는 그 아래에 표시된다.
- 신청자 상세와 정보 수정창의 메모 목록은 본문 전체를 여러 줄로 표시한다. 메모를
  더블클릭하면 상세 창이 열리고, 본문을 눌러 수정한 뒤 `저장`한다. `보관`과 `삭제`는
  활성 목록에 노출하지 않고 상세 창에서 제공한다. 보관한 메모는 현장 배부 화면의
  `보관함`에서 복원하거나 삭제한다. 보관함도 다른 대화상자와 같이 `Escape`로
  닫을 수 있다.
- 현장 배부와 신청자 관리 사이를 이동해도 각 목록의 스크롤·선택과 신청자 상세
  스크롤은 유지된다. 현장 배부 행의 점 세 개·우클릭 메뉴에서 `상세 정보 보기`를
  선택하면 해당 신청자의 신청자 관리 상세로 바로 이동한다.
- 점 세 개·우클릭 메뉴를 `Escape`로 닫으면 행 포커스가 풀린다. 이후 방향키로
  이동할 때는 선택과 포커스가 같은 행으로 함께 이동한다.
- 현장 배부에서 선택된 신청자 행에 `ArrowRight`를 누르면 오른쪽 메모 입력으로
  이동한다. 메모 입력은 일반 `Enter`로 저장하고 `Shift+Enter`로 줄을 바꾼다.
- 신청자 관리 검색창에서 `ArrowDown`으로 첫 신청자를 선택하고, 목록에서 위·아래
  방향키로 이동하면 오른쪽 상세가 함께 바뀐다. 첫 행에서 `ArrowUp`은 검색창으로
  돌아간다.
- 신청자 관리 상세의 `신청자 삭제`는 구독·배부·개별 구매·메모 이력이 전혀 없는
  잘못된 등록만 확인 후 영구 삭제한다. 이력이 있는 신청자는 삭제할 수 없으므로
  `보관`을 사용한다. 영구 삭제는 되돌릴 수 없다.
- `⌘/Ctrl+1`은 현장 배부, `⌘/Ctrl+2`는 신청자 관리로 이동한다. 입력창에
  포커스가 있어도 동작하며 열린 대화상자나 도움말 안에서는 동작하지 않는다.
- 구독 이력은 `시작`과 `끝` 호를 나눠 표시한다. `기존 XLSX` 같은 내부 출처와
  최초 이전용 메모는 데이터에는 남지만 상세 화면에는 반복해서 표시하지 않는다.
- 메모를 처리했거나 당분간 숨기려면 `보관`한다. 메모 추가·수정·보관·복원 직후에는
  상단 되돌리기/다시 실행 버튼 또는 `⌘/Ctrl+Z`, `⌘/Ctrl+Shift+Z`를 사용할 수 있다.
  `삭제`는 확인 후 영구 삭제되며 되돌릴 수 없으므로, 보관이 필요한 경우 삭제 대신
  보관을 사용한다.

## 4. 데이터 백업·복원

1. 기존 담당자가 `신청자 관리 → 데이터 백업·복원 → 전체 상태 내보내기`를 한다.
2. 생성된 XLSX의 요약 건수를 확인한다.
3. 파일에는 전체 이름과 전화번호가 있고 암호화되지 않으므로 안전하게 전달한다.
4. 새 담당자는 같은 버전 또는 호환 최신 앱에서 파일을 선택한다.
5. 새 PC의 상태만 사용할 때는 `교체`, 양쪽 작업을 합칠 때는 `병합`을 선택한다.
6. 동일인 후보와 변경 요약을 확인한 뒤 가져온다.
7. 결과가 잘못되면 앱을 재실행한 뒤에도 `가져오기 전 백업으로 복원`을 사용할 수
   있다. 복원 전에는 가져오기 이후 작업이 사라질 수 있음을 확인한다.
8. 인수인계가 끝나면 메일·메신저·다운로드 폴더의 불필요한 XLSX 사본을 삭제한다.

## 5. 문제 해결과 로그

앱의 `도움말 → 앱 정보`에서 정확한 앱 버전, 데이터 위치와 로그 위치를 확인할
수 있다. `로그 폴더 열기`로 `qt-manager.log`와 회전 파일을 찾는다. 로그에는
이름·전화번호·메모를 기록하지 않지만, 전달 전 내용과 수신자를 다시 확인한다.

앱이 실행되지 않으면 운영체제, 앱 버전, 발생 시각, 보이는 오류 문구와 로그를
개발 담당자에게 전달한다. 운영 XLSX나 SQLite 파일은 개인정보가 포함되므로 문제
재현에 꼭 필요한지 확인하지 않고 전달하지 않는다.

## 6. 검증 상태 안내

네이티브 E2E는 검증 환경에서 명시적으로 켠 경우에만 실행한다. 현재 Windows
실제 장치에서의 설치·실행·핵심 흐름 검증은 아직 완료되지 않았으므로, 배포 전에는
Windows 담당자가 설치와 한글 표시, 데이터 저장 및 핵심 배부 흐름을 별도로
확인한다.

## 7. 백업, 퇴임과 앱 삭제

- 전체 상태 가져오기 전 자동 복원 지점은 최신 10개가 로컬에 보관된다.
- 중요한 변경 전에는 전체 상태 XLSX를 별도 안전한 위치에 내보낸다.
- 앱 삭제만으로 로컬 데이터가 함께 삭제된다고 가정하지 않는다.
- 퇴임 담당자는 인수인계 완료와 새 담당자의 표본 확인 후, `도움말 → 앱 정보`에
  표시된 데이터 폴더와 개인적으로 보관한 XLSX 사본을 조직 정책에 따라 삭제한다.
- 데이터 폴더를 지우면 앱 상태와 자동 복원 지점을 되찾기 어려우므로 대상 경로를
  확인하고 앱을 완전히 종료한 뒤 처리한다.
