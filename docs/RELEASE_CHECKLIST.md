# QT Manager 릴리스 체크리스트

릴리스 버전: `0.1.0`

## 자동 검증

- [x] `package.json`, Cargo workspace, Tauri 설정 버전이 일치한다.
- [x] `just check`가 macOS와 Windows에서 통과한다.
- [x] `just e2e`의 전체 핵심 흐름이 macOS와 Windows에서 통과한다.
- [x] macOS Universal 앱에 `arm64`, `x86_64`가 모두 포함된다.
- [x] macOS DMG 무결성 검사와 Windows NSIS 설치 파일 생성 검사가 통과한다.
- [x] Windows NSIS 무인 설치 후 설치된 앱의 5초 실행 스모크 검사가 통과한다.
- [x] 런타임 원격 리소스와 동적 개인정보 로그 기록이 없음을 자동 검사한다.

### 2026-08-05 호스팅 릴리스 후보 결과

- GitHub Actions [`release-candidate` 실행 30972110172](https://github.com/benlee73/qtManager/actions/runs/30972110172)가 `macos-15`와 `windows-2025`에서 모두 성공했다.
- macOS는 `just check`, Tauri E2E 9개 통과·2개 선택 제외, Universal DMG 생성과
  `lipo` 아키텍처(`arm64`, `x86_64`)·`hdiutil verify` 무결성 검사를 통과했다.
- Windows 호스팅 x64는 `just check`, Edge 기반 Tauri E2E 9개 통과·2개 선택 제외,
  NSIS 생성, `/S` 무인 설치, 설치 실행 파일 확인과 5초 실행 스모크를 통과했다.
- 두 설치 파일은 Actions 아티팩트로 업로드됐다. 테스트 로그와 패키지에는 운영
  개인정보를 포함하지 않는다.
- 위 결과는 호스팅된 Windows x64와 macOS CI 검증이다. 실제 Windows 10·11 기기,
  Intel Mac 기기의 수동 설치·SmartScreen/Gatekeeper·배율 확인은 아래 항목을
  별도로 완료해야 한다.

## 실제 릴리스 후보 확인

- [ ] Apple Silicon macOS 12 이상에서 DMG 설치, 최초 실행, 한글 표시를 확인한다.
- [ ] Intel macOS 12 이상에서 DMG 설치, 최초 실행, 한글 표시를 확인한다.
- [ ] Windows 10 64비트에서 NSIS 설치, SmartScreen 안내, 한글 표시를 확인한다.
- [ ] Windows 11 64비트에서 NSIS 설치, SmartScreen 안내, 한글 표시를 확인한다.
- [ ] 각 OS에서 앱 종료·재실행 후 담당자, 배부, 확인할 일과 테마가 유지된다.
- [ ] 각 OS에서 XLSX 내보내기 → 다른 설치에서 가져오기 → 표본 상태를 대조한다.
- [ ] 1120×760 초기 창과 900×640 최소 창, 운영체제 배율에서 잘림·전체 스크롤이 없다.
- [ ] 앱 시작 시간, 설치 파일 크기와 유휴 메모리를 기록해 다음 릴리스 기준으로 남긴다.

## 개인정보와 인수인계

- [ ] 테스트 fixture, 캡처, 로그와 설치 패키지에 실제 운영 개인정보가 없다.
- [ ] XLSX 내보내기와 가져오기 화면에 암호화되지 않은 개인정보 파일 안내가 보인다.
- [ ] 로그에는 시각·레벨·고정 이벤트명만 있고 이름·전화번호·메모가 없다.
- [ ] 도움말에서 앱 버전, 데이터·로그 경로와 퇴임 담당자 사본 삭제 절차를 확인한다.
- [ ] 1120×760과 최소 900×640에서 76px 좌측 메뉴, 현재 메뉴 강조, 전체 문서
      스크롤 부재와 내부 목록 스크롤을 확인한다.
- [ ] 현장 배부 표에는 전화번호 열이 없고 이름·또래 검색, 이름 툴팁, 정보 수정과
      신청자 관리 화면에서는 전체 전화번호를 확인할 수 있다. 전화번호 검색은
      신청자 관리에서 동작한다.

## 배포

- [ ] Git 태그와 앱 버전이 일치한다.
- [ ] GitHub `release candidate` 워크플로의 두 설치 파일을 내려받아 해시를 기록한다.
- [ ] 내부 전달 메시지에 버전, 지원 OS, 미서명 경고와 이 안내서 위치를 포함한다.
- [ ] 새 담당자가 인수인계 XLSX 건수와 최근 배부 표본을 기존 담당자와 대조한다.
