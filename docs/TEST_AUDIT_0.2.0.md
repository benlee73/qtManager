## 정리·검증 원칙

- 옛 확인할 일/고정 메모 화면의 제외 E2E 2개와 그 전용 미사용 보조 함수를 제거했다. 현재 메모·관리·정정 흐름에서 각 핵심 책임을 검증한다. 실패 조건을 약하게 하거나 재시도로 숨기지 않는다.
- DOM 호출은 fixture 설정과 별도 백엔드 계약 확인에 사용한다. 실제 입력 오류의 검증은 실제 앱 컨트롤과 pointer/keyboard 결과를 확인한다.
- 익명 fixture와 임시 SQLite/XLSX만 사용한다. 실제 운영 DB를 바꾸거나 운영 자료를 테스트 fixture로 복사하지 않는다.
- 이전 자료용 carrier와 변환은 남기되 현재 메모 엔터티를 그 경로로 재생성하지 않는다. 중복된 memo 변환 구현을 한 호환 모듈로 합쳤다.
- 실측하지 않은 검색 성능이나 Windows DPI·IME 상태를 자동 검사 통과로 표기하지 않는다. 해당 항목은 별도 실행 증거가 필요하다.

## 로컬 실행 결과

- 2026-10-19 `just check` 통과: Python 2개, 프론트엔드 156개, Rust 전체 단위·통합·문서 검사, 포맷·정적 검사, E2E 엄격 타입 검사.
- 신규 업무 통합 검사 10개는 익명 SQLite/XLSX로 원자성·반복 요청·정정·메모 보존·정확 이름 우선 검색을 확인한다. 백업 미리보기 건수에는 이전 개인 메모도 포함한다.
- 옛 메모 변환 기반의 일회성 데이터 정리 도구는 현재 canonical Memo가 있는 DB에 적용을 거부한다. 과거 자료 분석과 마이그레이션 경로는 유지한다.
- macOS 실제 화면 E2E와 새 설치 파일, Windows 검증은 아직 완료로 표시하지 않는다.

### 실제 화면 검사에서 확인한 도구 경계

- Embedded WebDriver 1.2.0은 `KeyboardEvent`를 dispatch하지만 Enter의 암묵적 제출과 Space의 체크박스 기본 동작을 실행하지 않는다. 포커스를 명시한 상태에서도 재현하고 설치된 드라이버 구현을 확인했다.
- 연간 폼은 현재 호의 신청 + 배부와 다른 시작 호의 신청만 저장을 명시적으로 제출한다. 비활성 기본 버튼, 한글 조합 확정·키 반복, 사람 선택창에서 이미 처리한 Enter는 제출하지 않는 단위 검사 3개를 추가했다.
- 체크박스는 기본 브라우저 동작을 유지한다. 실제 라벨/입력 클릭과 목록 변화는 E2E로 검사하며 Space는 OS 설치 수동 검사로 남긴다.
- 최종 macOS E2E는 **29개 통과, 제외 0개**다. 테스트 초기화에서 창 복원·표시·포커스를 요청한 뒤 도움말 패널의 투명·화면 밖 정지 상태가 사라지고 애니메이션 진행과 본문 표시를 확인했다. Enter 신청 + 배부, 또래 예외, 배부 보존 연간 정정, 1달 정정, 필터 직접 클릭과 도움말 전환이 통과했다. 운영 앱의 애니메이션은 바꾸지 않았다.
- Universal 프로덕션 앱과 DMG 생성 성공, `lipo -verify_arch x86_64 arm64`, Info.plist 0.2.0, `hdiutil verify` 무결성을 확인했다. 에이전트 환경의 GUI/XPC·hdiutil 제약과 구분해 일반 터미널 실행 로그로 최종 성공을 확인했다. 실제 설치와 Windows 검증은 아직 남아 있다.
- 일반 macOS 터미널용 `just release-macos`는 E2E가 통과한 경우에만 Universal DMG 패키징을 실행한다. shell에 긴 bundle_args 인수가 잘못 전달되는 문제를 줄인다.
