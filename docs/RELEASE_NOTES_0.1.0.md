# QT Manager 0.1.0 릴리스 후보 기록

기준일: 2026-10-08

## 2026-10-08 필터 간격과 입금 화면 구분

- 신청자 필터를 작은 버튼 묶음으로 붙여 간격을 좁혔습니다.
- 입금 확인 필요는 주 작업 화면으로 강조하고 확인 내역은 대기로 돌아갈 수 있는 보조 조회 화면으로 구분했습니다.
- 입금 관리 전용 도움말과 화면별 안내를 추가하고 메모 검색·신청자 정렬·단축키 안내를 갱신했습니다.
- 신청자 목록은 기존 간이 등록 우선·이름순을 유지합니다. `⌘/Ctrl+3`은 새 빌드 설치 후 사용할 수 있습니다.

## 2026-10-06 신청자 필터와 입금 단축키

- 신청자 필터를 인원 수 없이 `전체 / 누락 / 보관` 한 줄로 표시합니다.
- `Ctrl+3`(macOS `⌘+3`)으로 입금 관리 화면을 엽니다.

## 2026-10-04 현장 배부 상단 메뉴 정리

- 검색창 옆의 `…` 메뉴와 `최근 구매 취소`를 제거했습니다. 구매 직후 실수는
  상단의 되돌리기로 취소할 수 있습니다.

## 2026-10-04 배부 전 메모 확인과 구독 바로가기

- 활성 연결 메모가 있는 사람은 배부 버튼을 누르면 메모가 표시되고, 확인 후에만
  배부됩니다. 취소하면 배부하지 않으며 메모가 없는 사람은 바로 처리됩니다.
- 검색창 옆에 `1년 구독`과 `1달 구독` 버튼을 배치했습니다. `1년 구독`은 기존
  현장 간이 등록, `1달 구독`은 기존 한 호 구매이며 실제 신청·구매 방식은 같습니다.

## 2026-10-04 검색한 신청자의 메모 우선 표시

- 현장 배부에서 이름·또래를 검색하면 해당 신청자의 연결 메모가 우측 목록 상단에
  표시됩니다. 다른 메모도 아래에 유지되며, 검색어를 지우면 최근 수정 순으로 돌아갑니다.

## 2026-08-31 네이티브 제목 표시줄 테마 동기화

- 라이트·다크 테마를 바꾸면 macOS·Windows 네이티브 제목 표시줄과 창 시스템
  컨트롤도 같은 명암으로 바뀝니다.
- 저장된 테마는 앱 시작 시 네이티브 창에 함께 적용되며, 첫 실행은 다크 테마로
  시작합니다. 운영체제 기본 제목 표시줄 스타일과 컨트롤은 그대로 유지합니다.

## 2026-08-31 도움말 모달 균형 조정

- 도움말을 중앙 68vw·68vh(약 70%)로 줄이고 헤더·목차·본문·카드의 여백을
  간결하게 조정했습니다.
- 좁은 창에서도 검색창이 헤더 높이를 불필요하게 늘리지 않으며, 본문은 모달
  안에서 계속 스크롤할 수 있습니다.

## 2026-08-31 도움말 우측 패널 전환

- 도움말을 화면 오른쪽 약 70~80% 폭의 전체 높이 패널로 표시해 본문을 넓게
  읽을 수 있게 했습니다.
- 패널은 180ms의 빠른 가로 슬라이드와 배경 페이드로 열리고 닫히며, 작은 창과
  동작 줄이기 환경에서도 레이아웃이 유지됩니다.

## 2026-08-08 최신 정리

- 신청자 등록·수정 연락처를 `010-xxxx-xxxx`로 자동 정규화하고 기존 유효한
  연락처도 마이그레이션에서 같은 형식으로 맞췄습니다.
- 선택한 호의 대상이 아닌 사람과 예정 구독자는 현장 배부 목록·집계에서 제외하고,
  만료자는 `구독 갱신`을 현장 배부 화면 위에서 바로 열 수 있게 했습니다.
- 신청자 관리 목록의 키보드 방향키가 스크롤 대신 선택 이동으로 동작하고, 목록
  경계·Escape에서 불필요한 포커스 테두리를 남기지 않도록 보정했습니다.
- 메모 상세의 연결 대상 이름을 제목 오른쪽에 배치하고, 도움말 패널을 창 크기에
  맞춰 확장했습니다. 도움말 검색과 백업 XLSX를 가져오는 빠른 시작 단계도
  추가했습니다.
- 사용자-facing 표현을 `스프레드시트 붙여넣기`로 통일하고 `?` 도움말 단축키를
  제거했습니다.
- 현장 개별 구매에서 이름·또래로 기존 신청자를 검색한 뒤 결과를 직접 선택해
  구매 이력을 연결할 수 있습니다. 결과가 없을 때는 `신규 인원으로 추가`를 선택해
  구독 없는 구매 전용 신청자를 만들 수 있으며, 기존 신청자의 상세에도 구매·전달
  이력이 표시됩니다. 자동 이름 매칭은 하지 않습니다.

## 포함 기능

- 선택한 QT 호 기준 연간 6개 호 구독과 만료 판정
- 현장 배부의 이름·또래 검색, 신청자 관리의 이름·또래·전화번호 검색, 여러 권
  전체·일부 배부와 되돌리기
- 복수 상태 필터, 정상 구독 상태 문구 간소화, 배부·취소·정보 수정·개별 구매의
  되돌리기와 다시 실행
- 신청자 연결 여부를 이름으로만 보조 표시하는 조밀한 우측 메모 목록과 선택 호
  간격 개선
- 정식·간이 신청자 등록, 구독 갱신, 스프레드시트 행 붙여넣기
- 미연결·신청자 연결 메모, 메모 보관함과 현장 개별 구매
- 전체 상태 XLSX 교체·병합, 자동 복원 지점과 가져오기 전 백업 복원
- 라이트·다크 테마, 1120×760 초기·900×640 최소 크기 조절 창과 오프라인 도움말
- 개인정보 비포함 회전 운영 로그와 앱 지원 경로
- 본문·표 머리글·라벨·메타정보를 역할별 크기로 정리해 현장 배부와 신청자 관리의
  글자 위계를 통일하고, 고정 창과 내부 스크롤 레이아웃을 유지함
- 신청자 행과 우측 메모 카드의 세로·내부 여백을 소폭 늘려 본문이 붙어 보이지
  않도록 조정함. 상단 통계·검색 영역과 창 크기, 내부 스크롤 정책은 유지함.
- 배부 수량 버튼은 고정 폭·높이로 키워 수량이 긴 경우에도 읽기 쉽게 하고,
  신청자 행 우클릭 메뉴는 누른 위치에 상세 보기·메모 추가·정보 수정 동작을
  표시함.
- 구독 이력 카드에서 시작·끝 호와 수량을 독립적으로 배치하고 갱신의 시작 연도·
  수량 입력 높이를 맞춤.
- 스프레드시트 붙여넣기 창 폭, 백업·복원 버튼 우선순위, 정보 툴팁 자동 줄바꿈과
  전화번호·구독 도움말 목록을 정비함. 입력 영역 밖에서는 브라우저 Reload 메뉴를
  노출하지 않음.
- 이슈 호 제목의 숫자·한국어 접미사 간격과 통계 수직 여백을 조정하고, 구독 이력의
  시작·끝·수량·상태 열을 정렬함.
- 스프레드시트 설명을 두 줄로 나누고, 붙여넣기 요약·수동 열 매핑·행 미리보기를
  격자로 정리함. 응답 행에서 Tab 문자를 입력할 수 있으며 텍스트 입력 중 `Ctrl/⌘+Z`
  는 앱 되돌리기에 가로채이지 않음.
- 갱신 시작 연도·수량은 추천 목록 없이 직접 입력하도록 단순화하고, 긴 정보 툴팁의
  폭이 무너지지 않도록 보정함.
- 신청자 관리의 검색·보관·집계·인원 목록을 저채도 영역으로 구분하고, `정보 보완
필요` 집계를 누르면 보완 대상 이름만 바로 확인할 수 있도록 함. 관리 상단
  버튼은 일반체로 통일하고 보관함 숫자 배지는 제거함.
- 스프레드시트 가져오기의 입금 제외 안내를 요약과 행 목록 사이의 보조 박스로
  배치하고, 구독 이력 수량·상태를 중앙 기준선에 맞춤. 기본 창은 1120×760으로
  시작하며 최소 900×640을 유지함.
- 검색창에서 `ArrowDown`으로 신청자 목록에 진입하고 위·아래 방향키로 이동할 수
  있습니다. 배부 행의 `Enter`는 확인창을 열고, 확인창에서 다시 `Enter`를 누르면
  배부를 확정합니다. `ArrowRight`는 메모 입력으로 이동하며 일반 `Enter`는 저장,
  `Shift+Enter`는 줄바꿈으로 동작합니다. 신청자 관리에서도 방향키 이동과 오른쪽
  상세 갱신을 지원합니다.
- 신청자 관리에서 마우스로 선택한 행도 키보드 포커스를 유지해 방향키로 신청자를
  이동할 수 있습니다. 이동 중에는 이전 상세를 유지해 깜빡임을 줄이고, `/`로
  관리 검색창에 바로 들어갑니다. 상세 하단의 신청자 보관·삭제는 같은 액션 그룹
  안에서 되돌릴 수 있는 보관과 파괴적 삭제를 구분해 제공합니다.
- 만료된 신청자의 현장 배부 행에서도 `구독 갱신`을 바로 실행할 수 있습니다. 버튼은
  만료 호의 배부를 허용하지 않고 신청자 관리의 해당 상세와 구독 추가·갱신 창으로
  이동합니다.

## 2026-08-07 도움말 문구·배치 보정

- 담당자 직접 수정 문구는 보존하고, 현장 개별 구매 안내를 실제 점 세 개 `기타
기능` 메뉴와 현재 선택 호 기준 입력 흐름에 맞췄습니다.
- 구독의 `보관된 구독` 관리 상태와 인수인계 백업·복원 순서를 도움말에 명시했습니다.
- 단축키·앱 정보 카드를 위아래로 배치하고 방향키 명칭을 한국어로 통일했으며,
  로그 폴더 열기 버튼은 보조 글자 크기로 조정했습니다.

## 2026-08-05 메모 통합

- 확인할 일·고정 메모·신청자 메모를 `메모` 한 종류로 통합하고, 미연결 메모에는
  별도 유형 표시를 붙이지 않음
- 메모 본문은 목록에서 여러 줄 전문으로 읽고, 카드를 더블클릭해 상세를 열어
  본문 클릭 편집·보관·복원·삭제를 수행함. 목록에는 보관·삭제 버튼을 표시하지 않음
- 신청자 상세와 정보 수정창의 연락처 아래에 연결 메모를 추가하고, 메모가 없는
  경우에도 입력칸과 안내 툴팁만 유지함
- SQLite schema v4·XLSX format v2로 새 `memos` 저장 구조를 사용하고 기존 기록과
  v1 XLSX는 무손실 호환 변환함
- 메모 생성 경로, 본문 줄바꿈, 상세 편집·보관·삭제, 보관함·복원 및 데이터 왕복을
  단위·통합·macOS Tauri E2E에서 검증함

## 2026-08-03 UI 정비

- 신청자 관리 목록을 내용 높이에 맞는 행으로 정리하고 목록에서는 전화번호를
  숨겼습니다. 전체 전화번호는 신청자 상세·수정에서 계속 확인할 수 있습니다.
- 신청자 상세에서 신청자 메모를 항상 표시하고, 연결된 미보관 확인할 일은
  전문과 상태를 읽기 전용으로 확인할 수 있습니다. 상태 변경은 현장 배부 화면에서
  하며 보관된 확인할 일은 그 화면의 보관함에서 확인·복원합니다.
- 신청자 관리의 구독은 오늘이 포함된 호를 기준으로 현재·예정·지난·보관 상태를
  표시합니다. 이는 관리용 분류일이며 실제 배부 자격은 현장 배부에서 선택한 호를
  기준으로 그대로 판정합니다.
- 구독·배부 표의 열 머리글과 라이트·다크 테마 경계선을 정비했습니다. 이 표시
  정비는 SQLite 마이그레이션이나 읽기 전용 조회 로그를 추가하지 않습니다.
- 신청자 관리의 `데이터 인수인계`를 기능을 더 바로 이해할 수 있는
  `데이터 백업·복원`으로 변경했습니다.
- 상단 내비게이션을 폭 76px의 좌측 레일로 바꿔 세로형 목록에 쓸 수 있는
  작업 영역 높이를 확보함
- 현장 배부 표에서는 전화번호 열을 숨겨 구독과 배부 상태의 가로 여유를 확보함
- 신청자 관리의 전화번호 검색과 행 툴팁·접근성 정보, 신청자 상세·수정 화면의
  전체 전화번호 접근은 그대로 유지함. 현장 배부 검색은 이름·또래만 사용함.
- 검색·필터 중에도 대상·완료·남음·배부 요약은 선택 호 전체 기준으로 유지함
- 현장 배부와 신청자 관리의 기본 글자 크기·행간을 함께 높이고, 브랜드 간격과
  입력값/placeholder 대비 및 확인할 일 입력 영역의 밀도를 조정함
- 의미 없는 담당자 초록 상태점을 제거하고, 확인할 일의 신청자 표시는 이름만
  남김. 신청자 수정창에서는 연결된 미보관 확인할 일의 전문과 상태를 확인할 수
  있음
- Dock·Windows·좌측 레일 아이콘을 동일한 원본으로 다시 만들고, 인디고 본체

## 2026-10-04 — 현장 신청 후속 관리

- 일반 신청자의 또래 누락은 등록 경로와 무관하게 정보 보완에 표시하고 연락처는 선택으로 유지한다. 현장 등록 후 관리 화면을 즉시 갱신한다.
- 새 1년·1달 구독의 입금 확인 대기를 신청자 관리에서 건별 조회·확인·취소하고 여러 건을 함께 처리한다. 기존 자료는 대상에 올리지 않고 마지막 안내 확인 응답은 무시한다. 현장 배부에는 입금을 표시하지 않는다.
- 군지체는 또래와 입금 예외로 분류하고 이름을 정리한다. 매 배부의 실제 권수를 누적하며 구독 대상 통계와 판매 통계에서 제외하고 실제 배부 권수에 포함한다. 기존 이력과 취소 관계를 보존한다.
- 1달 구독의 기존인 검색 결과가 없으면 자동 신규 등록한다. 현장 목록 더블클릭은 관리 상세로 이동한다.
- 활성 메모 본문·연결 이름 검색, 보관된 신청자만 보기, 상단 통계 전문 표시를 추가한다.
- SQLite schema 6·XLSX format 3을 도입하고 구버전 읽기를 유지한다. 운영 DB 마이그레이션 전 SQLite 안전 사본을 생성한다.

## 2026-10-05 — 독립 입금 관리 화면

- 독립 검색과 개별·일괄 확인, 확인 내역·취소, 되돌리기·다시 실행 및 새 신청·구매 반영을 유지한다. 이름을 누르면 신청자 관리 상세로 이동하며 보관된 신청자도 해당 필터에서 선택한다.
- 저장 형식과 기존 입금 로그·업무 변경 이력은 유지하고 화면 이동·조회에 새 이력을 기록하지 않는다.
