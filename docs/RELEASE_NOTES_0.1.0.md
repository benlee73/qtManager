# QT Manager 0.1.0 릴리스 후보 기록

기준일: 2026-07-27

## 포함 기능

- 선택한 QT 호 기준 연간 6개 호 구독과 만료 판정
- 이름·또래·전화번호 검색, 여러 권 전체·일부 배부와 되돌리기
- 복수 상태 필터, 정상 구독 상태 문구 간소화, 배부·취소·정보 수정·개별 구매의
  되돌리기와 다시 실행
- 신청자 확인할 일 상태점, 간결한 필터 요약, 조밀해진 우측 확인할 일과 선택 호
  간격 개선
- 정식·간이 신청자 등록, 구독 갱신, Google 응답 행 붙여넣기
- 확인할 일, 고정 메모, 신청자 메모와 현장 개별 구매
- 전체 상태 XLSX 교체·병합, 자동 복원 지점과 가져오기 되돌리기
- 라이트·다크 테마, 1000×720 초기·900×640 최소 크기 조절 창과 오프라인 도움말
- 개인정보 비포함 회전 운영 로그와 앱 지원 경로

## 2026-08-03 UI 정비

- 상단 내비게이션을 폭 76px의 좌측 레일로 바꿔 세로형 목록에 쓸 수 있는
  작업 영역 높이를 확보함
- 현장 배부 표에서는 전화번호 열을 숨겨 구독과 배부 상태의 가로 여유를 확보함
- 전화번호 검색과 행 툴팁·접근성 정보, 신청자 상세·수정 및 신청자 관리 화면의
  전체 전화번호 접근은 그대로 유지함
- 검색·필터 중에도 대상·완료·남음·배부 요약은 선택 호 전체 기준으로 유지함
- 현장 배부와 신청자 관리의 기본 글자 크기·행간을 함께 높이고, 브랜드 간격과
  입력값/placeholder 대비 및 확인할 일 입력 영역의 밀도를 조정함
- 의미 없는 담당자 초록 상태점을 제거하고, 확인할 일의 신청자 표시는 이름만
  남김. 신청자 수정창에서는 연결된 미보관 확인할 일의 전문과 상태를 확인할 수
  있음

## 2026-08-03 최초 이전 데이터 검증

- 남은 일반 확인 항목을 다음 담당자가 실제로 확인할 수 있도록 수량·또래·권별
  기간·시작 호 등의 구체적인 문구로 바꾸고, 확정된 9~10월호 종료 중복 구독은
  기존 배부 이력을 보존해 통합함
- 운영자가 확인한 7~8월 현장 신청을 연간 구독 6건과 현장 개별 구매 2건으로
  구분하고, 분리된 신청자 5명은 과거 구독·배부 이력을 보존해 통합함
- 기존 XLSX의 `26.05` 같은 두 자리 연도 날짜를 인식하도록 보완함
- 시작일과 종료일이 모두 있으면 연속 6개 호 규칙에 맞는지 교차 검증함
- 기존 `구독 시작 호 확인`은 원본과 현재 구독이 완전히 일치하고 수정 흔적이
  없는 경우만 정리하며, 적용 전 전체 상태 XLSX 복원 지점을 남김
- 기본 목록의 구독 종료를 달력 날짜 대신 `2027년 3~4월호까지`처럼 QT 호로
  표시해 실제 배부 자격 기준과 화면 표현을 일치시킴
- 원본 행으로 확정된 중복 신청자·갱신 구독 1건을 전체 상태 복원 지점 생성 후
  통합하고 기존 배부 기록을 올바른 갱신 구독에 보존함
- 같은 두 자리 연도 오인식으로 한 호 늦거나 중복 생성된 추가 대상은 원본
  기간·수량·행과 현재 수정 이력을 모두 대조한 뒤 일괄 교정함. 시작 호 4개,
  중복 신청자 10개와 잘못된 구독 8개를 정리하면서 배부·취소 기록 348개를
  보존했으며, 사용자가 확인 보류한 대상과 원본 미확정 사례는 그대로 유지함

| 항목                         | 결과                            |
| ---------------------------- | ------------------------------- |
| 실제 Tauri E2E               | 8개 흐름 통과                   |
| Apple Silicon 앱 크기        | 약 15MB                         |
| Apple Silicon DMG            | 4,936,171바이트, 무결성 확인    |
| Universal 앱 크기            | 약 31MB                         |
| Universal DMG                | 10,034,253바이트, 무결성 확인   |

크기와 메모리는 첫 릴리스의 비교 기준이다. 유휴 RSS는 운영체제와 측정 시점에 따라
달라질 수 있으므로 다음 릴리스에서도 같은 방식으로 추세를 비교한다.

## 배포 주의

이 후보는 교회 내부 배포용이며 코드 서명·공증하지 않는다. macOS Gatekeeper와
Windows SmartScreen 안내는 앱 도움말과 `docs/USER_GUIDE.md`를 따른다. 설치
파일에는 운영 데이터가 없지만, 앱이 내보낸 XLSX에는 개인정보가 있으므로 별도로
안전하게 전달하고 불필요한 사본을 삭제한다.
