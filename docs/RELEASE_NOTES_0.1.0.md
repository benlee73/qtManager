# QT Manager 0.1.0 릴리스 후보 기록

기준일: 2026-08-05

## 포함 기능

- 선택한 QT 호 기준 연간 6개 호 구독과 만료 판정
- 이름·또래·전화번호 검색, 여러 권 전체·일부 배부와 되돌리기
- 복수 상태 필터, 정상 구독 상태 문구 간소화, 배부·취소·정보 수정·개별 구매의
  되돌리기와 다시 실행
- 신청자 연결 여부를 이름으로만 보조 표시하는 조밀한 우측 메모 목록과 선택 호
  간격 개선
- 정식·간이 신청자 등록, 구독 갱신, Google 응답 행 붙여넣기
- 미연결·신청자 연결 메모, 메모 보관함과 현장 개별 구매
- 전체 상태 XLSX 교체·병합, 자동 복원 지점과 가져오기 전 백업 복원
- 라이트·다크 테마, 1000×720 초기·900×640 최소 크기 조절 창과 오프라인 도움말
- 개인정보 비포함 회전 운영 로그와 앱 지원 경로

## 2026-08-05 메모 통합

- 확인할 일·고정 메모·신청자 메모를 `메모` 한 종류로 통합하고, 미연결 메모에는
  별도 유형 표시를 붙이지 않음
- 메모 본문은 목록에서 여러 줄 전문으로 읽고, 카드를 더블클릭해 상세를 열어
  본문 클릭 편집·보관·복원·삭제를 수행함. 목록에는 보관·삭제 버튼을 표시하지 않음
- 신청자 상세와 정보 수정창의 연락처 아래에 연결 메모를 추가하고, 메모가 없는
  경우에도 입력칸과 안내 툴팁만 유지함
- SQLite schema v4·XLSX format v2로 새 `memos` 저장 구조를 사용하고 기존 기록과
  v1 XLSX는 무손실 호환 변환함
- 메모 생성 경로, 본문 줄바꿈, 상세 편집·보관·삭제, 보관함·복원 및 데이터 왕복을
  단위·통합·macOS Tauri E2E에서 검증함

## 2026-08-03 UI 정비

- 신청자 관리 목록을 내용 높이에 맞는 행으로 정리하고 목록에서는 전화번호를
  숨겼습니다. 전체 전화번호는 신청자 상세·수정에서 계속 확인할 수 있습니다.
- 신청자 상세에서 신청자 메모를 항상 표시하고, 연결된 미보관 확인할 일은
  전문과 상태를 읽기 전용으로 확인할 수 있습니다. 상태 변경은 현장 배부 화면에서
  하며 보관된 확인할 일은 그 화면의 보관함에서 확인·복원합니다.
- 신청자 관리의 구독은 오늘이 포함된 호를 기준으로 현재·예정·지난·보관 상태를
  표시합니다. 이는 관리용 분류일이며 실제 배부 자격은 현장 배부에서 선택한 호를
  기준으로 그대로 판정합니다.
- 구독·배부 표의 열 머리글과 라이트·다크 테마 경계선을 정비했습니다. 이 표시
  정비는 SQLite 마이그레이션이나 읽기 전용 조회 로그를 추가하지 않습니다.
- 신청자 관리의 `데이터 인수인계`를 기능을 더 바로 이해할 수 있는
  `데이터 백업·복원`으로 변경했습니다.
- 상단 내비게이션을 폭 76px의 좌측 레일로 바꿔 세로형 목록에 쓸 수 있는
  작업 영역 높이를 확보함
- 현장 배부 표에서는 전화번호 열을 숨겨 구독과 배부 상태의 가로 여유를 확보함
- 전화번호 검색과 행 툴팁·접근성 정보, 신청자 상세·수정 및 신청자 관리 화면의
  전체 전화번호 접근은 그대로 유지함
- 검색·필터 중에도 대상·완료·남음·배부 요약은 선택 호 전체 기준으로 유지함
- 현장 배부와 신청자 관리의 기본 글자 크기·행간을 함께 높이고, 브랜드 간격과
  입력값/placeholder 대비 및 확인할 일 입력 영역의 밀도를 조정함
- 의미 없는 담당자 초록 상태점을 제거하고, 확인할 일의 신청자 표시는 이름만
  남김. 신청자 수정창에서는 연결된 미보관 확인할 일의 전문과 상태를 확인할 수
  있음
- Dock·Windows·좌측 레일 아이콘을 동일한 원본으로 다시 만들고, 인디고 본체
  바깥의 흰 배경과 후광을 투명하게 제거하면서 본체 크기는 유지함
- 좌측 로고 아래 영문 워드마크를 한 줄 `큐티매니저`로 바꾸고 브랜드 아래
  구분선을 낮춰 하단 여백을 확보함

## 2026-08-04 신청자 관리 정보구조 정비

- 상단의 중복 제목을 하나의 `신청자 관리` 제목으로 통합했습니다.
- 왼쪽 신청자 목록과 오른쪽 신청자 상세를 각각 독립된 내부 스크롤 영역으로
  바꾸고 앱 전체 스크롤은 만들지 않았습니다.
- 신청자 상세의 또래 배지 오른쪽에 이름을 배치하고 연락처·상태를 그 아래에
  표시해 첫 시선에서 식별 정보를 함께 확인할 수 있게 했습니다.
- 신청자 관리 목록은 또래와 이름만 기본 표시하도록 줄이고, 정보 보완 필요·보관
  상태만 작은 표시로 보조합니다. 구독 건수와 마지막 대상 호는 행 안내·툴팁과
  상세에서 확인할 수 있으며, 선택 상태는 인디고 강조 하나로 통일했습니다.
- 라이트·다크 Tauri E2E에서 제목, 내부 스크롤 계약, 또래·이름의 가로 배치를
  검증했습니다.

## 2026-08-04 도움말 가독성 정비

- 긴 줄글을 업무 카드, 짧은 목록과 순서 단계로 나누어 필요한 조작을 한눈에
  찾을 수 있게 했습니다.
- `확인할 일·고정 메모`를 별도 목차 항목으로 분리하고, 신청자 연결은 현장 배부
  화면의 신청자 행에서 만드는 흐름으로 명확히 안내했습니다.
- 도움말을 현재 화면의 관련 섹션에서 열고, 본문 스크롤·목차 선택·고정 섹션
  제목을 서로 동기화했습니다.
- 도움말 버전 날짜와 관련 단위·Tauri E2E를 갱신했습니다.

## 2026-08-04 도움말 세부 표시 보정

- 상단의 반복 보조 문구를 제거하고 빠른 시작 카드의 단계 설명이 한 글자씩
  세로로 쪼개지지 않도록 본문 열 배치를 고쳤습니다.
- `Escape`로 도움말을 닫을 수 있게 했습니다.
- 앱 정보의 데이터·로그 경로는 줄바꿈으로 전체 값을 읽을 수 있고 기존 툴팁도
  유지됩니다.

## 2026-08-04 신청자 상세 입력과 이력 표시 보정

- 신청자 메모를 정보 수정창을 열지 않고 상세 화면에서 바로 수정·저장할 수
  있게 했습니다. 메모가 없는 상태는 노란 경고가 아닌 낮은 강조로 표시합니다.
- 연결된 확인할 일 영역에 해당 신청자와 연결되는 즉시 추가 입력을 넣었습니다.
- 구독 이력은 `시작`·`끝` 호로 나누고 `기존 XLSX`·최초 이전용 메모 같은 내부
  출처 정보는 저장·인수인계에는 보존하되 기본 상세 화면에서는 숨겼습니다.
- 보관 신청자 보기나 검색 재조회 중 현재 상세를 유지하고, 신청자 정보 수정
  대화상자의 폭을 관리 화면에 맞게 줄였습니다.

## 2026-08-04 신청자 상세·선택 상호작용 보정

- 신청자 메모의 별도 강조 박스와 빈 상태 문장을 제거하고, 입력칸과 안내
  툴팁만 남겼습니다. 연결 확인할 일이 없을 때 반복 문장도 표시하지 않습니다.
- `정식 등록` 상태 문구를 화면에서 제거하고 `신청자 등록`·`정보 보완`처럼
  실제 작업 중심의 표현을 사용합니다.
- 우클릭 메뉴를 `Escape`로 닫은 뒤 행에 남던 포커스 선을 해제하고, 방향키로
  이동할 때 선택과 포커스를 함께 이동해 두 행이 선택된 것처럼 보이지 않게 했습니다.
- 도움말 패널 바깥 배경을 클릭해 닫을 수 있게 했습니다.

## 2026-08-05 후속 UI·상태 보정

- 메모 상세 창의 본문 정렬·크기와 메모 목록 글자 크기를 조정하고, 보관함에
  `복원`과 `삭제`를 함께 제공했습니다.
- 신청자 정보 수정창에서 새 메모와 메모 편집 결과가 즉시 목록에 반영되고,
  메모 안내 툴팁이 긴 문장에서도 잘리지 않게 했습니다.
- 현장 배부 행 메뉴의 `상세 정보 보기`로 신청자 관리 상세를 열 수 있으며,
  두 화면 사이를 이동해도 각 화면의 스크롤·선택·상세 위치를 유지합니다.
- 대상·완료·남음·배부 통계를 균형 있게 가운데 정렬하고 신청자 관리 상단 여백을
  줄였습니다. 또래가 없는 활성 신청자도 `정보 보완 필요`에 포함합니다.
- 신청자 상세 배부 이력은 최신 QT 호부터 표시되며, 같은 호의 동일 처리 시각도
  수정 시각과 내부 ID로 안정적으로 정렬합니다. 메모 보관함은 `Escape`로 닫을
  수 있습니다. 단문 메모 상세 창의 빈 공간을 줄이고 긴 본문 편집은 기존 내부
  스크롤을 유지합니다.

## 검증 상태

- 네이티브 E2E는 검증 환경에서 명시적으로 opt-in할 때만 실행합니다.
- GitHub Actions 호스팅 `macos-15`·`windows-2025` 릴리스 후보에서 `just check`,
  Tauri E2E(9개 통과·2개 선택 제외), macOS Universal DMG 검증, Windows NSIS
  무인 설치·5초 실행 스모크를 완료했습니다. 상세 결과는
  [릴리스 체크리스트](RELEASE_CHECKLIST.md)의 2026-08-05 기록을 참고하세요.
- 이번 후속 UI 변경은 GitHub Actions 사용량을 아끼기 위해 로컬 검증만 수행했으며,
  사용자가 요청하면 다음 호스팅 macOS·Windows 검증을 실행합니다.
- Windows 10·11 실제 장치와 Intel Mac의 설치·실행·데이터 저장·XLSX 왕복 및
  배율/보안 경고 확인은 아직 별도 장비에서 진행해야 하므로, 이를 실제 기기
  검증 완료로 표시하지 않습니다.

## 2026-08-03 최초 이전 데이터 검증

- 남은 일반 확인 항목을 다음 담당자가 실제로 확인할 수 있도록 수량·또래·권별
  기간·시작 호 등의 구체적인 문구로 바꾸고, 확정된 9~10월호 종료 중복 구독은
  기존 배부 이력을 보존해 통합함
- 운영자가 확인한 7~8월 현장 신청을 연간 구독 6건과 현장 개별 구매 2건으로
  구분하고, 분리된 신청자 5명은 과거 구독·배부 이력을 보존해 통합함
- 기존 XLSX의 `26.05` 같은 두 자리 연도 날짜를 인식하도록 보완함
- 시작일과 종료일이 모두 있으면 연속 6개 호 규칙에 맞는지 교차 검증함
- 기존 `구독 시작 호 확인`은 원본과 현재 구독이 완전히 일치하고 수정 흔적이
  없는 경우만 정리하며, 적용 전 전체 상태 XLSX 복원 지점을 남김
- 기본 목록의 구독 종료를 달력 날짜 대신 `2027년 3~4월호까지`처럼 QT 호로
  표시해 실제 배부 자격 기준과 화면 표현을 일치시킴
- 원본 행으로 확정된 중복 신청자·갱신 구독 1건을 전체 상태 복원 지점 생성 후
  통합하고 기존 배부 기록을 올바른 갱신 구독에 보존함
- 같은 두 자리 연도 오인식으로 한 호 늦거나 중복 생성된 추가 대상은 원본
  기간·수량·행과 현재 수정 이력을 모두 대조한 뒤 일괄 교정함. 시작 호 4개,
  중복 신청자 10개와 잘못된 구독 8개를 정리하면서 배부·취소 기록 348개를
  보존했으며, 사용자가 확인 보류한 대상과 원본 미확정 사례는 그대로 유지함

## 배포 주의

이 후보는 교회 내부 배포용이며 코드 서명·공증하지 않는다. macOS Gatekeeper와
Windows SmartScreen 안내는 앱 도움말과 `docs/USER_GUIDE.md`를 따른다. 설치
파일에는 운영 데이터가 없지만, 앱이 내보낸 XLSX에는 개인정보가 있으므로 별도로
안전하게 전달하고 불필요한 사본을 삭제한다.
