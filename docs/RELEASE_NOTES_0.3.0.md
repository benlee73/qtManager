# QT Manager 0.3.0

- 신청자 정보를 수정한 뒤 되돌려도 ‘또래 해당 없음’이 원래 상태로 복원됩니다. 현장 배부와 신청자 관리에 모두 적용합니다.
- 군지체의 배부 이력에 마우스를 올리거나 키보드로 이동하면 작은 × 버튼이 나타납니다. 호·권수·시각을 확인한 뒤 선택한 기록만 삭제할 수 있습니다.
- 삭제한 기록은 배부 합계와 유효 이력 목록에서 빠지고, 원본·취소 기록과 업무 이력은 백업에 보존합니다. 삭제도 되돌리기·다시 실행을 지원합니다. 일반 신청자의 이력 삭제는 제공하지 않습니다.

SQLite v7·XLSX v4를 유지합니다. 기존 백업을 계속 읽을 수 있습니다. 이미 배포한 0.2.1 설치 파일에는 이 변경이 포함되지 않습니다.

이미 예외 값이 해제된 신청자는 정보 수정에서 ‘해당 없음’을 다시 선택해야 합니다. 누락과 의도적인 예외를 자동 추정해 운영 데이터를 바꾸지 않습니다.
