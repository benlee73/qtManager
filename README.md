# QT Manager

맑은샘광천교회 교육국의 QT 신청·구독·현장 배부를 관리하는 오프라인 데스크톱 앱입니다.
별도 서버나 인터넷 연결 없이 로컬 SQLite에 상태를 저장하고, 담당자 간에는 XLSX
백업 파일로 전체 상태를 전달합니다.

## 주요 기능

- QT 호별 신청자 검색과 1권·여러 권 배부, 부분 배부·취소·되돌리기
- 신청자·구독 이력 관리와 현장 만료자 갱신
- 스프레드시트/Excel 행 붙여넣기와 XLSX 전체 백업·복원
- 연결·미연결 메모, 보관함, 라이트·다크 테마
- macOS·Windows 공통 단축키와 앱 내 오프라인 도움말

## 처음 시작하기

1. 앱을 실행하고 현재 담당자 이름을 입력합니다.
2. 기존 백업 XLSX가 있으면 **신청자 관리 → 데이터 백업·복원 → XLSX 가져오기**로
   복원합니다.
3. 상단에서 배부할 QT 호를 선택하고 이름 또는 또래로 검색합니다.
4. 책을 전달한 뒤 신청자 행의 `N권 배부`를 누릅니다.

XLSX에는 이름·연락처 등 개인정보가 포함될 수 있고 암호화하지 않습니다. 파일을
전달·보관할 때 접근 권한을 확인하고, 불필요한 사본은 삭제하세요. 앱은 입금 여부를
저장하지 않습니다.

## 설치와 지원

릴리스의 macOS `.app`/`.dmg` 또는 Windows 설치 파일을 사용합니다. 서명되지 않은
배포 파일은 운영체제의 Gatekeeper·SmartScreen 경고가 표시될 수 있으며, 앱 도움말의
설치 문제 안내에서 최초 실행 절차를 확인할 수 있습니다. macOS 릴리스는 Intel과
Apple Silicon을 모두 지원하도록 Universal 빌드를 목표로 합니다.

앱에서 **도움말 → 앱 정보와 문제 보고**를 열면 로컬 데이터 위치, 로그 위치와 버전을
확인할 수 있습니다. 운영 로그에는 개인정보를 기록하지 않습니다.

## 개발

```bash
pnpm install
just check       # 포맷·lint·TypeScript/React·Rust·단위 테스트
just e2e         # macOS 로컬 Tauri E2E
just package     # 현재 OS 설치 패키지
```

프론트엔드는 `src/`, 업무 규칙과 저장소 어댑터는 `crates/`의 헥사고날 구조로 나뉩니다.
현재 요구사항·데이터 계약은 [PROJECT_SPEC.md](./PROJECT_SPEC.md), Codex 작업 규칙은
[AGENTS.md](./AGENTS.md), 담당자용 사용법은 [docs/USER_GUIDE.md](./docs/USER_GUIDE.md)에
기록합니다. 기능을 바꿀 때는 관련 테스트와 문서를 함께 갱신하고 커밋 전에 `just check`를
실행합니다.
